# Настройка рассылки Timeline через Яндекс

Инструкция для почтового ящика `goatwhstle@yandex.ru`.

## 1. Подготовить ящик

1. Войдите в [Яндекс Почту](https://mail.yandex.ru/) под аккаунтом `goatwhstle@yandex.ru`.
2. Откройте настройки → **Почтовые программы**.
3. Включите доступ к ящику по протоколу IMAP.
4. Включите **Пароли приложений и OAuth-токены**.

Если Яндекс предложит принять пользовательское соглашение, подтвердите его в веб-интерфейсе Почты.

## 2. Создать пароль приложения

1. Откройте [настройки безопасности Яндекс ID](https://yandex.ru/support/id/ru/authorization/app-passwords).
2. Перейдите в раздел **Пароли приложений**.
3. Выберите тип приложения **Почта**.
4. Назовите пароль, например `Timeline SMTP`.
5. Создайте пароль и сохраните его в менеджере секретов.

Пароль приложения отображается только один раз. По данным Яндекса, он может начать работать через 2–3 часа.

Пароль приложения нельзя коммитить в Git или добавлять в этот документ.

## 3. Настроить Timeline

В локальном `.env` или в секретах окружения укажите:

```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=587
SMTP_USERNAME=goatwhstle@yandex.ru
SMTP_PASSWORD=<пароль приложения Яндекс>
SMTP_STARTTLS=true
SMTP_TIMEOUT=15s

EMAIL_FROM=goatwhstle@yandex.ru
EMAIL_FROM_NAME=Timeline
```

`EMAIL_FROM` должен совпадать с `SMTP_USERNAME`. Иначе Яндекс может отклонить отправителя.

Для текущего SMTP-адаптера Timeline нужен порт `587`: приложение начинает обычное SMTP-соединение и затем включает STARTTLS. Порт `465` использует implicit TLS и текущим адаптером не поддерживается.

## 4. Проверить настройки в Яндексе

Перед проверкой Timeline отправьте одно письмо вручную из `goatwhstle@yandex.ru` на тестовый адрес. Это подтверждает, что ящик активен и не заблокирован для отправки.

Для проверки Timeline понадобится отдельный тестовый адрес получателя. Не используйте массовую рассылку на первом шаге.

Проверяемые свойства:

- SMTP-подключение к `smtp.yandex.ru:587`;
- STARTTLS;
- авторизацию паролем приложения;
- отправителя и отображаемое имя;
- русскую тему и текст письма;
- получение письма и отсутствие попадания в спам;
- повторную попытку при временной ошибке.

## 5. Безопасность

- Не передавайте пароль приложения в чат.
- Не добавляйте пароль в Git.
- Используйте отдельный пароль приложения только для Timeline.
- Включите двухфакторную аутентификацию для Яндекс ID.
- Для production храните SMTP-параметры в секретах окружения.
- Если пароль утёк, удалите его в Яндекс ID и создайте новый.
