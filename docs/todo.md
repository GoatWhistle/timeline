## Принятые решения

- [x] **Б1.** Каталог — **только авторизованным**. Снимает расхождения с ТЗ
      по разделам 2, 14.2 и 5.1: анонимного субъекта не появляется,
      «публичных страниц нет» остаётся верным, `notes` не утекают
- [x] **Б2.** **Самозапись разрешена.** Участник жмёт «участвую» и сам
      указывает роль. Требует правки ТЗ разделов 2 и 6
- [x] **Б3.** География — **две независимые категории**:
      `format` (`ONLINE`/`OFFLINE`/`HYBRID`, NOT NULL) + `country_code`
      (обязателен при офлайне и гибриде, для гибрида — страна финала);
      `origin` (`RU`/`WORLD`, NOT NULL, умолчание `RU`). Виды строятся по
      `origin`, фильтр формата поверх
- [x] **Б4.** Комментарии — **буквальный ноль**, включая docstring. Ссылки
      на разделы ТЗ переезжают в таблицу трассировки в `docs/`
- [x] **Б5.** Почасовая сетка **не нужна**. Митап рисуется моментом (ромбом),
      а не полосой — тогда вечернее событие не схлопывается в чёрточку при
      масштабе недели, и часовая сетка не требуется
- [x] **Б6.** **Митапы делаются сразу**, прайм-версия. `kind` в той же
      таблице. **`hackathon` → `event` во всей системе**: таблица, 17 внешних
      ключей, типы, сервисы, endpoint-ы, папки. Держать в схеме имя, которым
      называется половина строк, — закреплённая ложь. Слово «хакатон»
      остаётся только там, где речь о виде `kind = HACKATHON`

**Миграции разрешено править**, а не только добавлять новые — поля
географии вносятся прямо в `000002_hackathons.up.sql`, отдельная миграция и
умолчания для старых строк не нужны.

**Go на машине нет — проверки backend идут в контейнере.** В `Makefile`
добавлены `back-build`, `back-cover` и переменная `GO_RUN`: при наличии
локального Go используется он, иначе тот же образ `golang:1.25-alpine`, что и
в сборке, с томом под кэш модулей. `make verify` работает без Go на машине.

# Если времени нет

Порядок урезания задан заранее, чтобы не решать в спешке.

**Минимум из трёх этапов: 0б, 1, 5а.** Срочные исправления снимают нарушение
доступности и холостую мемоизацию, токены дают обе темы, шкала — то, ради
чего продукт затевался.

**Порядок отказа:** реальное время → каталог и география → перестройка
структуры → локализация.

**Не откладывается никогда:** этап 0б, тесты прав перед этапом 6, умолчание
`Europe/Moscow` при вводе таймзоны.
