Language flags in flag-paths.ts

Source: flag-icons - https://github.com/lipis/flag-icons
Retrieved: 2026-09-02, from flags/4x3/<code>.svg

Only the two flags the language picker can display were taken into the
repository, not the upstream set of 250+ flags: `ru` for Russian and `gb` for
English. Each flag was reduced to its list of fill-and-path pairs; the path
geometry itself is unchanged, and the colours are the upstream ones because a
flag that follows the interface theme would no longer be that flag.

The flag-icons project is distributed under the MIT license, reproduced below.

The flag is decoration, not the signal: every option keeps the name of the
language beside it, and the flag itself carries `aria-hidden` so a screen
reader announces the language rather than a country. A country is not a
language - English is drawn with the flag of the United Kingdom, which names
neither the language nor every place it is spoken.
