Browser and operating system glyphs in browser-glyphs.ts and platform-glyphs.ts

Source: theSVG - https://github.com/glincker/thesvg
Retrieved: 2026-09-14, from public/icons/<slug>/mono.svg.

Each mark was reduced to a single path and recoloured to currentColor so it
follows the interface theme; the path geometry itself is unchanged.

Taken from mono.svg unaltered: Google Chrome (google-chrome), Firefox
(firefox), Safari (safari), Opera (opera), Yandex (yandex), Android (android),
Linux (linux).

Taken with the deviations named below, because no mono.svg exists upstream for
these slugs:

  Edge (microsoft-edge/default.svg) - the default carries six paths, three
  shapes each drawn twice: once flat and once again under a gradient that
  shades it. The three distinct shapes were concatenated into one path and the
  duplicate shading copies dropped. That is the whole mark and nothing was
  redrawn.

  Windows (windows/default.svg) - already a single path; only its fixed blue
  was replaced with currentColor.

  iOS and macOS (apple/mono.svg) - the ios and macos mono files are wordmarks
  that spell out "iOS" and "macOS" in letters, which does not read as an icon
  beside a browser mark. The Apple logo is used for both instead.

Not taken: ChromeOS. The upstream set has no ChromeOS icon under any slug, so
that platform falls back to the lucide "Monitor" glyph already bundled with the
product (lucide-react, ISC license). No geometry was invented for it.

Not taken either: the upstream AWS Architecture icons, which carry a separate
and more restrictive CC BY-ND 2.0 license. No icon in these files comes from
that set.
